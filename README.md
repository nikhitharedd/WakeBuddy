
# 🌙 WakeBuddy – Smart Sleep Tracker

## 📌 About the Project

WakeBuddy is a Smart Sleep Tracker developed using HTML, CSS, and JavaScript. It helps users monitor their sleeping habits, maintain a healthy sleep schedule, and understand their sleep patterns.

The application provides a simple and user-friendly dashboard to record sleep details, set alarms, receive bedtime reminders, and visualize weekly sleep statistics.

## ✨ Features

- **Sleep–Wake Tracker:** Record bedtime and wake-up time.
- **Alarm Scheduler:** Set and stop wake-up alarms.
- **Sleep Reminder:** Set daily bedtime reminders.
- **Sleep Pattern Analyzer:** Calculate average sleep duration and sleep goals.
- **Sleep History:** View and delete previous sleep records.
- **Weekly Sleep Graph:** Visualize sleep duration over seven days.
- **Dashboard:** Display important sleep statistics.
- **Responsive Design:** Works on desktop and mobile screens.
- **Local Storage:** Save sleep records in the browser.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Chart.js
- Browser LocalStorage
- Web Notifications API

## 🚀 How to Run the Project

1. Clone the repository:

   ```bash
   git clone https://github.com/nikhitharedd/WakeBuddy.git
   ```

2. Open the project folder in VS Code.

3. Open `index.html`.

4. Run it using the Live Server extension.

5. Start tracking your sleep!
